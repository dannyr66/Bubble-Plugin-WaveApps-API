# Rally hook ads

Meta ads plan for Rally, adapted from a short-form explainer on the five B2B SaaS hook types (circumstance, real reason, price tag, receipt, proof drop).

- `index.html` is the full plan in the Rally new look. Part 1 covers the five ad mock-ups, storyboards, funnel and test plan. Part 2 is the Demo Form Kit adapted to Rally's Start free signup (gate question, routing, event ladder, signal math calculator, add-back order and checklists). The kit's consultation pitch was left out. Published at https://claude.ai/artifact/RkJTLBR77JoL9WmgiTQUAS
- `video/` contains three fully generated concept videos (AI voice plus animated Rally screens) and the code that makes them. See `video/README.md`.
- `scripts.json` holds the five scripts in structured form (said and shown lines, timed beats, talent) for producing or generating the videos later.

Anything in `[brackets]` is a placeholder for real Rally data: the price, booking counts and proof numbers.
